# Search Playbook

## Goal

Find the smallest set of high-value sources that can answer the research questions with traceable evidence.

## Discovery loop

Use this loop repeatedly:

1. broad search;
2. identify names, job titles, quest/episode/chapter names, production terms, and source hubs;
3. search those terms directly;
4. trace secondary claims back to originals;
5. extract evidence;
6. search specifically for missing or contradictory evidence.

## Query families

### Work + analytical topic

- `[work] character writing [character]`
- `[work] relationship writing [characters]`
- `[work] narrative design`
- `[work] quest design`
- `[work] environmental storytelling`
- `[work] cinematic design`
- `[work] exposition worldbuilding`

### Creator-proximate

- `[creator] [work] interview`
- `[creator] [character/quest]`
- `[work] GDC`
- `[work] postmortem`
- `[studio] narrative designer [work]`
- `[writer/designer] talk [work]`

### Primary recovery

When a secondary article quotes a creator:

- search the exact short phrase;
- search speaker + outlet + topic;
- search article title fragments;
- search the event/podcast/video named by the article.

### Scene/quest-level

- `[quest/scene] designer`
- `[quest/scene] commentary`
- `[quest/scene] making of`
- `[character] introduction scene design`
- `[ending] writer interview`

### Reception / interpretation

- `[work] [topic] analysis`
- `[character] character analysis`
- `[quest] discussion`
- `[work] criticism [theme]`

Use reception queries only when audience interpretation or effect matters.

## Search order

Default order:

1. official/developer sources;
2. named creator talks/interviews;
3. professional trade coverage and specialist journalism;
4. reference sites/wikis;
5. community and video essays.

Break this order when a lower-tier source provides the terminology needed to find a primary source.

## Source-hub strategy

Once a strong source hub is found, search within it before returning to generic search.

Examples of source hubs:

- studio news/blog/archive;
- GDC Vault or conference channel;
- creator's official YouTube/Twitch/podcast archive;
- specialist publication interview archive;
- official wiki/database or documentation portal.

## Negative search

Actively search for evidence that can falsify the emerging thesis.

Examples:

- creator statements that contradict the interpretation;
- scenes that break the proposed pattern;
- alternate routes/endings;
- criticism explaining why the technique failed for some audiences;
- production constraints that provide a simpler explanation.

## Saturation rule

Consider a research question saturated when:

- major claims have high-quality evidence;
- new searches mostly return duplicates or references to already-collected originals;
- meaningful counterevidence has been sought;
- remaining gaps are explicit and unlikely to change the core conclusion.

Do not stop merely because a persuasive narrative has formed.
