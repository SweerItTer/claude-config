## Documentation governance

- Detailed rules: `docs/dev-guide/document-governance.md`
- Repository path mapping: `.project-governance.json` when custom paths are used
- Requirements: `docs/requirement/`, stable `R` IDs
- Specs and decisions: `docs/specs/`, stable `S` IDs and `Sxx-Dn` decisions
- Repeatable procedures: `docs/dev-guide/`
- One-time evidence: `docs/analysis/`
- Superseded or completed history: `docs/archive/`
- `docs/TODO.md` contains only current actionable work
- Stable R/S identity remains visible even when a relative link is provided
